# Fixed, curated library set for code skill sandboxes. Pinned deliberately —
# the only way to add a library is a commit here + image rebuild/redeploy,
# never something an uploaded bundle or the LLM can control at runtime.
#
# Sourced by scanning every skill in github.com/anthropics/skills (the
# reference Agent Skills catalog) and github.com/openai/skills (Codex's skill
# catalog) for third-party imports and requirements.txt files, so the base
# image can run the pdf/docx/pptx/xlsx/slack-gif-creator/security-ownership-map
# skills out of the box. Deliberately excluded: playwright/node (webapp-testing,
# web-artifacts-builder, playwright — browser/JS tooling, out of scope for this
# Python sandbox), anthropic/mcp/openai SDKs (mcp-builder, speech, transcribe,
# imagegen — dev-time/API meta-skills needing outbound network access, which
# sandboxes don't have by default), and the openai/skills deploy/SaaS-CLI
# skills (cloudflare-deploy, vercel-deploy, figma-*, notion-*, linear, sentry,
# gh-*, etc. — orchestrate external platforms over the network, not a library gap).
