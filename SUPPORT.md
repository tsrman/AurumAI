# Support

Use public issues for reproducible bugs and feature requests. Describe the source
revision, runtime, affected component, expected/actual behavior and commands that
reproduce the problem with synthetic data. Use the issue templates.

Start with [QUICKSTART](QUICKSTART.md), [configuration](docs/CONFIGURATION.md),
[testing](docs/TESTING.md) and the service-specific README. For architecture or
deployment questions, provide relevant sanitized settings rather than a complete
environment dump.

Do not attach API keys, tokens, user conversations, production data, browser
storage state, screenshots containing private information, or recovery journals.
Security issues use [the private reporting procedure](SECURITY.md).

This is a community source project with best-effort support. No commercial support
or response SLA is implied by this repository.
